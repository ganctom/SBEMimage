### Granular Acceptance Criteria Mapping

- **`AC-AA-FP-008` (Immediate Step 1 Cut Sensitivity)**: In production run `2026-10-30_171229`, Step 1 (the initial batch of 3 cuts) must trigger `contact_detected == True` on at least one probe tile, preventing the delayed cut detection observed previously.
- **`AC-AA-FP-009` (Air Approach Zero False Positive Rate)**: Across all 7 production air runs (`143927`, `144723`, `145034`, `145242`, `145618`, `145806`, `151539`), `contact_detected` must evaluate to `False` on Step 1 (0% FP).
- **`AC-AA-FP-010` (Full Regression Suite Clean)**: All tests in `tests/test_auto_approach.py` pass cleanly under Python 3.7.6 with zero regressions.
- **`AC-AA-FP-011` (Ultra-Thin Cut Sensitivity on Run 181342)**: In production run `2026-10-30_181342`, Step 1 (the first cut step) must evaluate to `contact_detected == True` on probe tiles with dissimilarity $d \ge 0.3100$.
- **`AC-AA-FP-012` (Immediate Cut Sensitivity on Run 171229)**: In production run `2026-10-30_171229`, Step 1 must trigger `contact_detected == True` ($d \ge 0.9000$), eliminating the 1-cut delay.
- **`AC-AA-FP-013` (Zero False-Positive Rate in Air)**: Across all 7 production air runs (`143927`, `144723`, `145034`, `145242`, `145618`, `145806`, `151539`), Step 1 evaluates to `contact_detected == False` with zero false positives under the tile-specific structural contrast thresholds ($d < d_{\text{trigger}}(\text{tile})$).
- **`AC-AA-FP-014` (10% Center-Crop Subpixel Registration Robustness)**: `register_and_crop()` performs `phase_cross_correlation` on the central 80% $\times$ 80% (10% cropped from all 4 borders) to eliminate raster edge transients, correctly recovering stage wander up to $15\,\mu\text{m}$.
- **`AC-AA-FP-015` (Clean Suite & Python 3.7.6 Compatibility)**: All tests in `tests/test_auto_approach.py` pass without regression; zero Python 3.8+ syntax.
- **`AC-AA-FP-016` (Live refresh of the Approach UI in Viewport)**: When automated approach is ongoing and processing or acquisition of any approach reference tile is done, all relevant GUI items in the Approach Tab in Viewport immediately refresh (image, approach controls).
- **`AC-AA-FP-017` (Present registered tile series in the Approach Tab)**: When the user scrolls through approach images in the Approach Tab in Viewport by mouse or slider, every image series is presented in an aligned form registered to the baseline across both Raw and Cyan/Magenta modes.
- **`AC-AA-FP-018` (Asynchronous stage movement between approach reference tiles)**: When the acquisition of an approach reference tile is completed, stage movement to the subsequent reference tile executes asynchronously during the image processing phase, accelerating the procedure and allowing residual stage drift to settle prior to subsequent frame acquisition.
